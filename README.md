# Практическая работа №4. Наследование, интерфейсы и полиморфизм

**Вариант:** А · Воин (лимит массы 6000 г, здоровье Алии 120)
**JDK:** OpenJDK 21.0.12 (`java -version` → `openjdk version "21.0.12.1"`)

## Структура

```
practice04/src/kz/javaworkshop/
  Item.java       абстрактный предмет (имя, масса, стоимость, describe/attackBonus/defenceBonus)
  Weapon.java     оружие, урон 1-100, переопределяет attackBonus() и describe()
  Armor.java      броня, защита 1-100, переопределяет defenceBonus() и describe()
  Potion.java     зелье, лечение 1-100, реализует Usable
  Food.java       еда, лечение 1-100, реализует Usable
  Usable.java     интерфейс с методом use(Hero)
  Inventory.java  рюкзак на массиве Item[] с лимитом массы (из предыдущей работы)
  Hero.java       герой: здоровье, attackPower(), defencePower(), takeHit(), heal(), useItem()
  Main.java       сценарии шагов 6 и 7
```

Maven не используется, пакет `kz.javaworkshop` сохранён.

## Сборка и запуск (из папки practice04, PowerShell)

```powershell
javac -encoding UTF-8 -d out (Get-ChildItem -Recurse src -Filter *.java).FullName
java -cp out kz.javaworkshop.Main
```

Linux / macOS:

```bash
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out kz.javaworkshop.Main
```

Если русский текст в консоли искажён, перед запуском выполните `chcp 65001`
(в Linux при необходимости: `java -Dfile.encoding=UTF-8 -Dstdout.encoding=UTF-8 ...`).

## Проверка границ (шаг 7)

Все 21 проверка в `Main` пройдена (`Итого: пройдено 21, не пройдено 0`). Три на выбор:

1. **Удар 1000.** Здоровье становится 0 (не отрицательным), возвращена фактическая потеря 100.
2. **Зелье при полном здоровье.** `useItem(0)` → `true`, зелье удалено из рюкзака, здоровье равно максимальному.
3. **Урон оружия 0 и 101.** Конструктор `Weapon` выбрасывает `IllegalArgumentException: Урон: 1-100`.

Проверка компиляции: при добавлении в `Main` строки `new Item("Камень", 100, 0)`
`javac` отклоняет её с сообщением:

```
error: Item is abstract; cannot be instantiated
```

Строка после проверки удалена.
